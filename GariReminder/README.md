# Gari PUC Reminder (Android)

## APK banano
1. Android Studio (Koala ba notun) install korun.
2. File > Open > ei `GariReminder` folder.
3. Gradle sync hobe (internet lagbe, prothombar).
4. Build > Build Bundle(s)/APK(s) > Build APK(s).
5. APK ta `app/build/outputs/apk/debug/` e pabe. Phone e copy kore install korun.

## Phone setting (khub dorkar)
- Prothombar app khulle SMS permission Allow korun.
- Settings > Apps > Gari PUC Reminder > Battery > **Unrestricted** korun,
  noyto Android background e daily check bondho kore dite pare.

## Excel/CSV format (prothom row heading)
Gari No | Naam | Phone | Issue Date | Last Date

## Notes
- Daily 10:00 AM e auto check hoy. Last date er 3 din age (ba tar pore phone off thakle porer bar) ekbar SMS jay.
- Word/Photo theke 1ta gari hole form e prefill hoy, apni check kore Save korben.
